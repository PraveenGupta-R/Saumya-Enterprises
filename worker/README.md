# Saumya Enterprises – Worker API

Cloudflare Worker (Hono) + D1 (SQL) + R2 (images). The same Worker serves the Angular static build
(`dist/saumya-enterprises/browser`) and falls back to `index.csr.html` for routes that were not prerendered
(e.g. `/admin/*`, products/posts added later).

## Local development

```powershell
npm run db:init     # create local D1 tables + seed from seed/seed.json (safe to re-run)
npm run api         # Worker on http://localhost:8787 (needs dist/ folder to exist; `ng build` creates it)
npm start           # Angular dev server, proxies /api -> :8787
```

Local secrets live in `.dev.vars` (git-ignored; see `.dev.vars.example`). Local state is in `.wrangler/state`.
Local admin login: the `ADMIN_EMAIL` / `ADMIN_PASSWORD` from `.dev.vars`.

## Secrets / variables

| Name | Required | Purpose |
|---|---|---|
| `ADMIN_EMAIL` | yes | Owner login email |
| `ADMIN_PASSWORD` | yes (first login) | Bootstrap password. On first successful login it is stored as a PBKDF2-SHA256 hash in D1 (`settings.admin_auth`); after that it can be changed in the admin panel and the env value is ignored |
| `SESSION_SECRET` | yes | HMAC key for the session cookie (use 48+ random chars; changing it logs everybody out) |
| `RESEND_API_KEY`, `MAIL_FROM`, `NOTIFY_EMAIL` | optional | Inquiry emails via Resend. All three are needed; otherwise emails are skipped and inquiries are still saved |

## Deploy

```powershell
npx wrangler login
npx wrangler d1 create saumya-enterprises          # paste the printed database_id into wrangler.jsonc
npx wrangler r2 bucket create saumya-enterprises-media
npx wrangler secret put ADMIN_EMAIL
npx wrangler secret put ADMIN_PASSWORD
npx wrangler secret put SESSION_SECRET
# optional email:
npx wrangler secret put RESEND_API_KEY
npx wrangler secret put MAIL_FROM
npx wrangler secret put NOTIFY_EMAIL
npm run db:init:remote                             # migrations + seed on the remote DB
npm run deploy                                     # ng build + wrangler deploy
```

Then add the custom domain in the Cloudflare dashboard (Workers → saumya-enterprises → Settings → Domains)
and set `siteUrl` in Admin → Settings (used by sitemap/robots).

## Endpoints

JSON uses the camelCase types in `src/app/core/models.ts`. Errors are `{ "error": "message" }`.

### Public
| Method & path | Notes |
|---|---|
| `GET /api/settings` | `SiteSettings` |
| `GET /api/categories` | `Category[]` |
| `GET /api/products`, `GET /api/products/:slug` | published only, sorted by `sort` |
| `GET /api/certifications` | published only |
| `GET /api/posts`, `GET /api/posts/:slug` | published, newest first (list includes `body`) |
| `GET /api/testimonials` | published only |
| `POST /api/inquiries` | body `InquiryInput` → `201 {ok:true,id}`. Honeypot `website` filled → `200 {ok:true,id:0}` (not saved). 5/hour/IP → 429 |
| `GET /api/media/:key` | R2 image, immutable cache |
| `GET /sitemap.xml`, `GET /robots.txt` | dynamic, 1 h cache, base URL = `settings.siteUrl` (falls back to request origin) |

### Admin (cookie `se_admin`; every non-GET needs header `X-Requested-With: XMLHttpRequest`)
| Method & path | Notes |
|---|---|
| `POST /api/admin/login` | `{email,password}` → `{ok,email}` + cookie. 5 failures / 15 min / IP → 429 |
| `POST /api/admin/logout` | clears cookie |
| `GET /api/admin/me` | `{ok,email}` or 401 |
| `POST /api/admin/password` | `{current,next}` (next ≥ 10 chars) |
| `GET /api/admin/stats` | `AdminStats` |
| `GET/POST /api/admin/{products,categories,certifications,posts,testimonials}` | list (all rows) / create → 201 saved object |
| `GET/PUT/DELETE /api/admin/<entity>/:id` | PUT accepts partial bodies (merged onto existing); DELETE → `{ok:true}` |
| `GET /api/admin/inquiries?status=&q=` | newest first |
| `GET /api/admin/inquiries.csv?status=&q=` | UTF-8 CSV with BOM; cells starting `= + - @` get a leading `'` |
| `GET/PUT/DELETE /api/admin/inquiries/:id` | PUT `{status?,notes?}` |
| `GET/PUT /api/admin/settings` | PUT merges onto existing `SiteSettings` |
| `POST /api/admin/media` | multipart field `file` (JPEG/PNG/WebP, ≤ 5 MB, magic-byte checked) → `201 {url:'/api/media/<key>'}` |
| `DELETE /api/admin/media/:key` | removes an uploaded file |

Product/category/post slug clash → `409`. Slug / key fields are auto-generated from the name/title when omitted.

## Files
- `index.ts` – entry: API router, static assets with SPA fallback, security headers
- `public.ts`, `admin.ts` – routes · `entities.ts` – row mappers + validation · `lib.ts` – crypto, validation, rate limiting
- `email.ts` – Resend emails · `seo.ts` – sitemap/robots
- `migrations/0001_init.sql` – schema · `seed.sql` – generated by `scripts/gen-seed.mjs` from `seed/seed.json`
